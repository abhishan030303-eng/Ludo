# ABHI LUDO v2 — Real Offline Playable Ludo

This is a real offline playable Ludo game, not a static mockup.

## Working game systems
- 2/3/4 player Pass & Play
- Offline Computer opponent
- Quick game mode
- Real dice roll animation
- Tap-to-move glowing legal tokens
- Six required to leave yard
- 52-cell movement + 6 home-lane cells
- Safe-star cells
- Capturing with extra turn
- Six gives another turn
- Winner detection
- Local coins, daily reward, shop and inventory
- Sound/vibration settings
- No online backend required

## Android
GitHub Actions builds a debug APK automatically from `.github/workflows/build-apk.yml`.


## V3 Dice Upgrade
Realistic CSS 3D dice with beveled faces, real pip layouts, depth/shadow and rolling animation.


## App Icon
ABHI LUDO now includes a branded app icon in `assets/` plus `favicon.png` and `manifest.webmanifest`.
For a native Android APK, copy the generated PNG into the Android `mipmap-*` launcher icon resources (or run Capacitor asset generation) before the final APK build.


## V5 — Pawn/Cone Goti
Movable Ludo goti are pawn/cone-shaped with a spherical top, tapered body, white rim, depth/shadow and a stronger glow when legally movable.
